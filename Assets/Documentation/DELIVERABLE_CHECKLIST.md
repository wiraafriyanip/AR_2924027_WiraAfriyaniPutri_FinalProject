# Checklist Pengumpulan P09, P10, P11 — Kelompok 4

## Tahap A — Generate project
- [ ] Unity Editor 6000.5.10f1 terbuka.
- [ ] Packages resolve tanpa error merah.
- [ ] Menu `0 - BUILD COMPLETE P09-P11 PROJECT` selesai.
- [ ] Menu `5 - VALIDATE GENERATED ASSETS` lulus.
- [ ] ReferenceImageLibrary berisi Marker_PinkBotanical (0.15 × 0.15 m).
- [ ] Prefab taman memiliki child geometry dan material permanen.
- [ ] Tiga scene tersedia.

## P09 — AR Foundation
- [ ] AR Foundation 6.5.1 dan Google ARCore XR Plugin 6.5.1.
- [ ] Google ARCore aktif pada XR Plug-in Management > Android.
- [ ] Hierarchy: AR Session, XR Origin, AR Camera.
- [ ] AR Camera memiliki AR Camera Manager dan AR Camera Background.
- [ ] Build APK P09 berhasil.
- [ ] Izin kamera diberikan dan feed kamera tampil di HP.

## P10 — Image Tracking
- [ ] Kandidat marker dibandingkan.
- [ ] Marker final Pink Botanical dipilih.
- [ ] Marker dicetak pada ukuran 15 × 15 cm dan diukur.
- [ ] RefImageLibrary_FinalProject memiliki Marker_PinkBotanical.
- [ ] Specify Size aktif dan ukuran sesuai marker cetak.
- [ ] AR Tracked Image Manager menggunakan library.
- [ ] Marker terdeteksi pada HP Android.

## P11 — 3D Object on Marker
- [ ] Prefab_PinkBotanicalGarden dibuat.
- [ ] Prefab menampilkan child geometry di Prefab Mode.
- [ ] Prefab memiliki ProceduralFlowerGarden.
- [ ] Sembilan material permanen tersedia.
- [ ] XR Origin memiliki AR Tracked Image Manager.
- [ ] AR Image Prefab Spawner memiliki Image Manager dan Content Prefab.
- [ ] Target Reference Name sama persis dengan Marker_PinkBotanical.
- [ ] Library terhubung ke AR Tracked Image Manager.
- [ ] Build APK P11 berhasil.
- [ ] Diorama tampil pada marker di HP.
- [ ] Objek mengikuti pergerakan marker.
- [ ] Pengujian jarak, sudut, dan pencahayaan dilakukan.
- [ ] Video demonstrasi 20–60 detik direkam.
